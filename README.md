## 🚀 Flagship work

**[macedonian-llm](https://github.com/gzimjusufi/macedonian-llm)** — First open-source instruction-tuned LLM for Macedonian.
Built the full pipeline from scratch: data collection/cleaning (10K docs), instruction-tuning, and evaluation. Cut perplexity by 51% vs. the base model. *Stack: Python, PyTorch/Transformers.*

**[albanian-llm](https://github.com/gzimjusufi/albanian-llm)** — Same pipeline, extended and adapted for Albanian.
58% perplexity reduction. Proves the pipeline generalizes across low-resource languages, not a one-off. *Stack: Python, PyTorch/Transformers.*

**[airwatch](https://github.com/gzimjusufi/airwatch)** — IoT air-quality monitor with an AI dashboard.
PM2.5/SCD40/AHT20+BMP280 sensors streaming to ThingSpeak, surfaced through an LLM-powered (Qwen) dashboard deployed on Vercel. End-to-end: hardware → data pipeline → AI layer → product.
